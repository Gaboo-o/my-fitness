title Exercise Library

User->Frontend:Open Exercise Library
Frontend->FlaskAPI:GET /api/exercises
FlaskAPI->ExerciseService:Request exercise list
ExerciseService->JSONStorage:Read exercises.json
JSONStorage-->ExerciseService:Return exercise data
ExerciseService-->FlaskAPI:Return exercise list
FlaskAPI-->Frontend:Return exercises as JSON
Frontend-->User:Display exercise library

title Filter Exercises by Workout Type and Location

User->Frontend:Select workout type and location
User->Frontend:Click Apply Filters
Frontend->FlaskAPI:GET /api/exercises with\nselected filter values
FlaskAPI->ExerciseService:Request matching exercises
ExerciseService->JSONStorage:Read exercises.json
JSONStorage-->ExerciseService:Return exercise data
ExerciseService->ExerciseService:Filter exercises by\ntype and location
ExerciseService-->FlaskAPI:Return filtered exercises
FlaskAPI-->Frontend:Return filtered results as JSON
Frontend-->User:Display matching exercises

title Pick a Workout for Me

User->Frontend:Select workout preferences
User->Frontend:Click Pick a Workout for Me
Frontend->FlaskAPI:POST /api/workouts/generate\nwith workout preferences
FlaskAPI->WorkoutService:Request generated workout
WorkoutService->ExerciseService:Get exercises matching preferences
ExerciseService->JSONStorage:Read exercises.json
JSONStorage-->ExerciseService:Return exercise data
ExerciseService->ExerciseService:Filter matching exercises
ExerciseService-->WorkoutService:Return matching exercises
WorkoutService->WorkoutService:Select exercises for workout
WorkoutService-->FlaskAPI:Return generated workout
FlaskAPI-->Frontend:Return workout as JSON
Frontend-->User:Display recommended workout

title Personal Profile

JSONStorage-->ProfileService:Return profile data
ProfileService-->FlaskAPI:Return profile
FlaskAPI-->Frontend:Return profile as JSON
Frontend-->User:Display profile information

User->Frontend:Edit profile information
User->Frontend:Click Save Profile
Frontend->FlaskAPI:PUT /api/profile with profile data
FlaskAPI->ProfileService:Validate and save profile
ProfileService->JSONStorage:Write profile.json
JSONStorage-->ProfileService:Confirm save
ProfileService-->FlaskAPI:Save successful
FlaskAPI-->Frontend:Return success response
Frontend-->User:Display profile saved message

title Complete and Save Workout

User->Frontend:Click Complete Workout
Frontend->Frontend:Collect workout exercises and duration
Frontend->FlaskAPI:POST /api/history with completed workout
FlaskAPI->HistoryService:Create workout history record
HistoryService->JSONStorage:Read history.json
JSONStorage-->HistoryService:Return existing workout history
HistoryService->JSONStorage:Write updated history.json
JSONStorage-->HistoryService:Confirm write
HistoryService-->FlaskAPI:Workout saved
FlaskAPI-->Frontend:Return success response
Frontend-->User:Display workout completed message

title Workout History and Progress
