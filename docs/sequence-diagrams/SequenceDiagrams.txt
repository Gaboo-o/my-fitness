title BMI Tracking - Calculate Body Mass Index

actor User
participant Frontend
participant FlaskAPI
participant BMIService
participant ProfileService
participant WeightService
participant JSONStorage

User->Frontend: Open BMI Calculator
User->Frontend: Click Calculate BMI
Frontend->FlaskAPI: Request BMI calculation
FlaskAPI->BMIService: Calculate BMI

BMIService->ProfileService: Get stored height
ProfileService->JSONStorage: Read user profile
ProfileService<--JSONStorage: Return height
BMIService<--ProfileService: Height value

BMIService->WeightService: Get latest weight
WeightService->JSONStorage: Read weight history
WeightService<--JSONStorage: Return weight entries
BMIService<--WeightService: Latest weight value

alt Valid height and weight available
    BMIService->BMIService: Convert height to meters
    BMIService->BMIService: Convert weight to kilograms
    note over BMIService: BMI = weight / (height * height)
    BMIService->BMIService: Calculate BMI
    FlaskAPI<--BMIService: Return BMI result
    Frontend<--FlaskAPI: BMI value
    User<--Frontend: Display BMI result
else Missing height or weight
    FlaskAPI<--BMIService: Missing measurement error
    Frontend<--FlaskAPI: Error response
    User<--Frontend: Request missing measurements
end
